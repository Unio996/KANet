# 预言机：让区块链相信"现实世界发生了什么"

> 给从没接触过 KANet 的开发者 / AI agent 看。先讲为什么这么设计，再讲怎么用。

---

## 1. 它解决的问题

区块链很擅长一件事：**严格执行写死的规则**。但它有个天生的盲点——**它看不见链外的真实世界**。

举个例子。两个人打赌："2026 世界杯阿根廷夺冠吗？" 钱锁在一个智能合约里。比赛结束了，阿根廷赢了——可是**合约自己不知道**。它没有眼睛，读不了新闻，看不了比分。

这时就需要一个**预言机（Oracle）**：一座把"现实世界的事实"安全送上链的桥。谁赢了、比特币现在多少钱、某件事到底发生没有——预言机负责给区块链一个**可信的答案**，合约才能照答案把钱付给对的人。

难点不在"取个数据"，而在 **"凭什么相信这个答案没被人做手脚"**。这份文档讲的就是 KANet 的预言机如何把"可信"这件事做扎实。

## 2. 最重要的一条原则：判不了，就弃权（不许猜）

KANet 预言机的根基只有一句话：

> **取不到可靠证据，就诚实说"我不知道"（弃权），绝不瞎猜。**

英文叫 **abstain-not-guess**。

为什么这条最重要？因为一个**会猜**的预言机比没有预言机更危险——它会信誓旦旦地给出一个错答案，合约照着错答案把钱付错人，而且没人知道它其实是蒙的。

所以 KANet 的设计里，每个判断结果只有三种：**YES（是）/ NO（否）/ ABSTAIN（弃权）**。当证据拿不到、或拿到的东西读不出明确结论时，系统**主动选 ABSTAIN**，把这一单退回去（退款，或交给后备机制），而不是硬给一个 YES 或 NO。

这条原则让预言机可以"安全地长大"——后面我们给它加越来越强的本事时，只要守住"判不了就弃权"，就永远不会因为"想多判几个"而砸了信任。

> `[图2]` 三个出口的分叉路牌：YES / NO / ABSTAIN。一个判官走到证据不足的路口，明确选了 ABSTAIN 那条，旁边标注"诚实弃权 > 自信猜错"。

---

## 3. 怎么判：不是一个人说了算，是一个委员会

如果只有一个判官，他被收买或出错，整个结果就毁了。所以 KANet 用**委员会**。

一个预测市场到期时，会有**若干名预言机委员**（比如 5 名）**各自独立**对同一个问题做判断。每人给出自己的 YES / NO / ABSTAIN。

然后看**多数**：需要达到约定的门槛（比如 **5 名里至少 4 名一致**）才算数，结果才会被采纳、合约才会按它结算。

关键词是 **"各自独立"**：每名委员都跑自己的判断流程，互不抄答案。这样单个委员就算想作弊，也撼动不了多数。

> `[图3]` 5 个判官小人各自看自己的证据、各自举牌（YES/YES/YES/YES/ABSTAIN）。下方一个计票框："4/5 一致 → 采纳 YES"。强调每人之间没有连线（独立）。

---

## 4. 怎么取证：去可信的源头，只取干净的事实

每名委员判断前要先**取证**。KANet 不让 AI 凭印象瞎答，而是去**指定的可信数据源**抓事实，再把**干净的结果**喂给判断模型。

目前内置的取证源（会持续扩充）：

| 问题类型 | 源头 | 取什么 |
|---|---|---|
| 体育赛果 | ESPN | 比赛的胜方 + 最终比分 |
| 加密货币价格 | CoinGecko | 实时价格 |
| 部分主观/复杂事件 | UMA 等后备机制 | 见第 6 节 |

两个细节体现了"不猜"的纪律：

- **没 final 不判**：比如体育赛事，只有当数据源明确标记"比赛已结束"时才出证据；还没打完 → 取证返回空 → 委员**弃权**。
- **忠实抽取**：取到的事实（比如"BTC = 107000 USD"）**原样**喂给判断模型，不替它做语义推理。是不是 ≥ 某个门槛，让模型对着真实数字判，而不是取证环节先替它下结论。

> `[图4]` 一条流水线：问题 → 去 ESPN/CoinGecko 抓页面 → 抽取器剪出"干净的一句事实" → 喂给判官。在"抓页面"和"抽取"之间画个漏斗，标注"只留干净事实，丢掉噪音"。

### 开市前先体检（prevet）

还有一道前置闸：一个市场**被创建之前**，系统会**预先试跑**它的取证器。如果这个问题根本取不到可判的证据（比如数据源不支持、格式读不出），就**直接拒绝建这个市场**。

这样平台上**只会出现"判得了"的市场**，从源头堵住了"建一个没法裁决的赌局"。

## 5. 怎么防作弊

可信的核心是"作弊划不来"。KANet 叠了好几层：

1. **委员会 + 多数门槛**：单个委员撼动不了结果（第 3 节）。
2. **各自独立判断**：委员之间不抄答案，避免"一个错带歪一片"。
3. **源头防伪造**：取证只认**白名单的真实域名**，并且用严格的主机名匹配（host-anchored），堵死 `evil.com/espn.com…` 这类把假地址伪装成真源的攻击（否则攻击者就能自己造证据骗结算）。
4. **质押 + 罚没（staking / slashing）**：委员要押上一笔保证金。投错、偷懒（该取证不取证乱投）会被**罚没**保证金。诚实干活有奖励，作弊或摆烂赔钱。
5. **后备仲裁（UMA）**：AI 现在判不了的事，交给 UMA 这类"乐观预言机"——先给一个答案 + 一段**挑战期**，任何人发现不对都能在挑战期内提出异议。

这几层合起来：**想作弊要同时骗过多数独立委员、绕过源头白名单、还得愿意赔上质押**——成本远高于收益。

> `[图5]` 一个"防作弊洋葱图"，从内到外五层：①多数门槛 ②独立判断 ③源头白名单 ④质押罚没 ⑤UMA 后备。外面一个拿着假证据的小偷被层层挡住。

## 6. 它会越来越强（北极星）

今天 KANet 预言机主要能判**结构化、单一来源**的客观事实（赛果、币价）。判不了的，老实交给 UMA 后备。但这只是**起点，不是天花板**。

设计上它的"判断能力"是**一档一档加上去**的：

```
档0 现状：单一来源、单页事实（ESPN / CoinGecko）
档1：扩更多结构化源（更多体育 / 数据 API）
档2：多源交叉印证（两个以上来源都对上才判，对不上就弃权）
档3：受限网络搜索（白名单源集内检索）
档4：工具调用（链上查询 / 计算器 / 专用 API）
档5：开放网络搜索（最广、也最需要强弃权 + 体检把关）
```

每升一档，**能判的问题集变大、对 UMA 的依赖变小**。而每一档都**始终守着第 2 节那条铁律**：判得了的判，判不了的诚实弃权。

> 北极星只有一个：**拿到更真实、更准确的信息来判。** 取证、弃权、委员会、开市体检、UMA、以及未来的新技能，全都为这一个目标服务。

> `[图6]` 一个上升的阶梯，台阶从"单页事实"到"开放网搜"，越高越宽（能判的范围越大）。每级台阶侧面都贴一张小标签"判不了→弃权"，强调能力涨但底线不变。

## 7. 如果你要用它

你不需要自己运行预言机——它是平台内置的。你会以两种身份接触到它：

- **建市场的人**：你提一个可判的问题（带上判定标准 + 数据源）。系统**预先体检**（prevet）；通过了市场才开，没通过会告诉你"这个问题现在判不了"。
- **下注 / 参与的人**：到期时委员会自动取证、投票、按多数结算，把钱付给对的一方——**全程自动、全程可审计**（每一步都有链上记录可查）。

如果系统对某个市场**弃权**了，钱会安全退回 / 走后备仲裁，**不会被一个瞎猜的答案吞掉**。这正是整套设计想给你的保证。

---

### 一句话总结

KANet 预言机是一座**"判不了就老实弃权、判得了就多委员独立取证 + 多数定案 + 作弊赔钱"**的可信之桥，而且这座桥的承重能力会一档一档变强——目标永远是：**给区块链更真实、更准确的现实世界事实。**
