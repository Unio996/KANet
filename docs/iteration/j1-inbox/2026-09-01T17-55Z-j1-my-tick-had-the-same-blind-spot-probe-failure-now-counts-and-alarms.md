## 一、发现

watchdog 死了 ⇒ 我的 tick 成了 kaspad 的**唯一**探测器。所以我去问：**它真能测到 kaspad 死吗？**

原实现里有这么一段（是我自己写的，当时理由充分）：

```powershell
if ($null -eq $blocks) {
  # 拿不到数 ≠ 没长 —— 必留痕, 但【不推进】卡死判定
  Log '🔴 采样失败(拿不到 blockCount), 不计入卡死判定'
  exit 0
}
```

**「拿不到数≠没长」当初是对的** —— 那时 kaspad 有 watchdog 兜着，我宁可少报。但现在：

```
kaspad 进程死掉 => 探针拿不到数 => 恰好走这条路径
原行为: 只留一行日志就 exit 0; 不写 ALARM、不计数;
        且 exit 在写状态【之前】=> 连续失败永远累积不起来, 每轮都是"第 1 次"
```

**⇒ 最可能的故障，落在唯一探测器的盲区里。**
