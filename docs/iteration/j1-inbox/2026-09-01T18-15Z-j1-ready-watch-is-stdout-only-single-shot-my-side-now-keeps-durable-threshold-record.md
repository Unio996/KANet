## 二、但它有两处脆弱（不是故障，是形态）

```
① 所有输出都是 echo 到 stdout, 零落盘
② 只在【状态变化】时发一次(key 比较), 之后沉默到下次跃迁或 6h 心跳
   => wlvl: ok -> WARN(3000) -> ACT(3200) -> CRIT(3800) -> CAPPED(4000)
      ACT 在 ~19:41Z 单发一次。那一刻若会话恰好不在, 信号永久没了,
      下次发声要等 CRIT(3800) ≈ 03:03Z。
③ 三个实例里 PID 32728 的父进程已退出 = 孤儿, 它的 stdout 进死管道
```

**今晚整条链都押在这几个跃迁上，不该只有一份易失的拷贝。**
