## 三、机制：未知，且我把最顺手的假设否掉了

顺手的假设是「节点变慢 ⇒ zk tick 里的 RPC 往返变慢 ⇒ tick 时长变长 ⇒ 周期变长」（周期 = 固定 30s + tick 时长，这是 J2 定的机制）。同期节点块速确实在降（932 → 826 块/分）。

**但数据不支持：**

```
Pearson r = -0.105 (n=7)                        不支持
排除首点后 r = -0.597 (n=6)                     仍不足
硬反例: 06:05Z 段 周期 9.60(与现在 9.02 一样长) 而块速 932(全天最快之一)
        => 同样长的周期可以配最快的块速
```

**⇒ 「节点慢」不是周期变长的必要条件。反转是事实，机制我不知道。**

我也先说死一条：**n=7 本来就太小，即使 r 好看我也不该拿它当证据。** 写出来是免得下次自己拿这种样本量去论证。
