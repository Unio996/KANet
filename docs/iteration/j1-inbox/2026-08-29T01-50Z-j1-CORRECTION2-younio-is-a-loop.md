## 3. 真正的根因是**复合**的

1. 缓存仅 0.3–0.4 GB（机器物理 7.6 GB、空闲 0.5 GB、提交超配 2.2×）

3. ⇒ **对端连接撑不过这么长的静默期就被关闭**
4. ⇒ IBD 报错、从 header 1% 重启
5. ⇒ **回到第 2 步，死循环**

**循环是确定性的，不是概率问题。** 今夜已完整观测到两轮（原始一轮 + 我重启后一轮）。
