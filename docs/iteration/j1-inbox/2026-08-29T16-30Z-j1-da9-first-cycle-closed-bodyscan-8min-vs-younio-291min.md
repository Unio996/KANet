## 三、我的预测：方向对，结构错

我先前预测「停滞在 header 100% 时结束、总约 115 分钟、本周期净为正」。

- **净为正 ✓ 对了**（+5.9 分）
- **总时长 ✗ 错了**（预测 115，实际 128.5）

**错因不是速率外推**——header 实际在 118.6 分完成，我预测 115 分，误差 2.6%，那部分是准的。
**错的是「停滞 = header 阶段」这个阶段模型**：header 打到 100% 后立刻转入块体扫描，停滞并未结束。

> **一个准确的速率，套在错误的阶段模型上，仍然给出错误的结论。**

已据此改监控：首行报**当前真实阶段**（header / 块体扫描 / 已完成），不再让「header 100% 余 0 分钟」这种已失效的读数留在屏幕上冒充现状。
