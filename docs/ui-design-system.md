# KANet UI Design System v2

> 2026-03-28 确认定稿。亮色暖调，实用简洁高效清晰。

## 四原则

| 原则 | 定义 |
|------|------|
| 实用 | 每个像素都有功能。不装饰，不炫技。界面存在的唯一理由是帮用户完成任务。 |
| 简洁 | 信息密度适中，留白充足。一眼能看到重点，不用找。减法设计。 |
| 高效 | 关键操作一步到位。状态一目了然。不让用户等、猜、翻页。 |
| 清晰 | 层次分明，语义色一致。数据和操作的边界清楚。三层可验证，深浅自选。 |

## 配色

### 背景层次（暖白系）

| 用途 | 色值 | 说明 |
|------|------|------|
| Base | `#f7f6f3` | 页面底色，暖灰白 |
| Card | `#ffffff` | 卡片/面板，纯白 |
| Subtle | `#faf9f7` | 次级区域、聊天背景 |
| Input | `#efeee9` | 输入框底色 |
| Border | `#e4e2dc` | 分隔线、卡片边框 |

### 品牌蓝（唯一强调色）

| 级别 | 色值 | 用途 |
|------|------|------|
| 50 | `#eff6ff` | 用户气泡底、hover 背景 |
| 100 | `#dbeafe` | hover 加深 |
| 500 | `#3b82f6` | 主按钮、链接 |
| 600 | `#2563eb` | pressed 状态 |
| 700 | `#1d4ed8` | 导航激活 |

### 语义色

| 语义 | 背景 | 前景 |
|------|------|------|
| 成功/在线/完成 | `#f0fdf4` border `#bbf7d0` | `#16a34a` |
| 警告/等待中 | `#fffbeb` border `#fde68a` | `#d97706` |
| 错误/危险/离线 | `#fef2f2` border `#fecaca` | `#dc2626` |
| 信息/中性 | `#eff6ff` border `#bfdbfe` | `#2563eb` |

### 文字层次

| 层级 | 色值 | 用途 |
|------|------|------|
| Primary | `#1a1a2e` | 标题、关键数据、操作按钮 |
| Secondary | `#4a4b57` | 正文内容、说明文字 |
| Tertiary | `#9496a1` | 时间戳、辅助标签、占位符 |
| Disabled | `#c8c8d0` | 禁用状态 |

## 排版

- **字体**: Inter, -apple-system, BlinkMacSystemFont, sans-serif
- **等宽**: 系统 monospace（链上地址、TX hash）

| 级别 | 大小 | 粗细 | 用途 |
|------|------|------|------|
| Page Title | 22px | Semibold | 页面标题 |
| Section | 15px | Medium | 区块标题 |
| Body | 14px | Regular | 正文 |
| Caption | 12px | Regular | 时间戳、注释 |
| Mono | 13px | Regular mono | 链上数据 |

## 圆角

| 大小 | 用途 |
|------|------|
| 12px | 卡片、面板（主容器） |
| 8px | 按钮、输入框、数据区（功能组件） |
| 4px | 小标签、badge（最小单元） |

## 间距

| 名称 | 大小 | 用途 |
|------|------|------|
| 紧凑 | 8px | 行内元素 |
| 标准 | 16px | 卡片内边距 |
| 舒适 | 24px | 卡片间距 |
| 区块 | 40px | 大区块分隔 |

## 阴影

- 极克制，仅浮层用 `shadow-sm`
- 卡片靠 border 而非阴影区分层次

## 组件规范

### Agent 消息
- 左侧 8x8 头像（圆角 lg，品牌蓝渐变）
- 白底气泡，warm-200 边框，shadow-sm
- 左上角缺圆角 `rounded-tl-sm`

### 用户消息
- 右对齐
- brand-50 底色，brand-100 边框
- 右上角缺圆角 `rounded-tr-sm`

### 状态卡片（三层可验证）
- **第一层（默认）**: 人话。绿点 + 标题 + 一句话描述 + "详情"链接
- **第二层（展开）**: 规则。warm-50 底色，key-value 对齐布局
- **第三层（展开）**: 证据。warm-100 底色，等宽字体，TX hash 可点击

### 快捷操作
- 圆角 8px 小按钮
- 主操作: brand-50 底 + brand-600 字
- 次操作: warm-100 底 + ink-400 字

### 导航
- 文字导航，不用 emoji 图标
- 当前页: brand-500 字色 + font-medium
- 非当前页: ink-300

## 不做清单

- 不用渐变背景、玻璃拟态
- 不用 emoji 做导航图标
- 不做纯装饰动画
- 不在第一层暴露技术细节
- 不用药丸形按钮（full rounded）
- 不用深色主题

## 参考风格

- Linear 的简洁
- Stripe 的可信
- Notion 的温暖底色
- 不像交易所盯盘界面
- 不像 AI chatbot 的花哨泡泡
