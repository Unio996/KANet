# 候选 A · 存量市场遗留费率证明(precond6 R-3.4-(甲))· v0.1 草判据

## §0 (甲)要解的那一个问题
R-3 已实测坐实(J1 v0.2.1 + J2 三版本):存量 subset② 市场的 `maker_fee_bps`/`oracle_fee_bps` **在链上/DB 四个权威源全部零命中**,恒取部署代码常量(maker=10 / oracle=100,`pool-market-settler.js:2244-2245` `|| 10 / || 100`,`[CONFIRMED·源码实读]`;DB 无列 `[CONFIRMED·DB实读]`)。⇒ 候选 A 对存量必然 `verifier-inconclusive`,且 covenant 烤死不可补 ctor 权威。(i) 只救新盘。**存量需要一个不改 covenant、不撒谎的费率权威来源。**

## §1 (甲)的核心命题(它成立当且仅当下面全真)
🔴 **(甲)不是"给存量发明费率",是把【一个已经是事实的、且已封闭的历史属性】一次性承诺下来**:
1. **它是事实**: 存量费率**从来就是协议常量**(无 per-market 变体存在过 —— DB 零费率列、ctor 零费率参数、体内零引用,三处独立证)。(甲) 承诺的字面就是这个事实,不引入任何未曾发生的 per-market 值。
2. **它是封闭集**: 遗留集 = **(i) ctor 变更部署【之前】建的全部市场**。cutover 之后新市场走 (i)、不入遗留集 ⇒ 遗留集是**有限、只减不增、可枚举**的。

## §2 遗留证明对象(`legacy_fee_attestation`)最低要求(缺一不成立,回落 inconclusive)
复用 `fact-receipt`(`docs/2026-08-04-fact-receipt-typed-schema-and-domain-digest-design.md`)域分隔规则,**不另立第二套**:
1. **绑定谓词而非枚举**: 承诺的是"**cutover_daa 之前建的市场,其 maker_fee_bps≡10、oracle_fee_bps≡100**"这条**谓词 + cutover_daa 边界**,不是逐市场列表(逐市场列表会随存量数膨胀且引入维护面)。候选 A 对某存量盘求费率权威 = 验"该盘 created 落在 cutover_daa 之前" ∧ 取谓词常量。
2. **cutover_daa 必须有独立权威**: 边界 daa 一旦承诺即不可变;它的权威**不能**来自本证明自身(自证循环)——须锚在 (i) 部署那笔链上动作/版本切换的独立可核事件上(`[未验/需 J1 定 (i) 部署形态后回填]`)。
3. **由 pk 被不可变前态绑定的权威签署**(同 J1 `policy_receipt` §R-3.4-(ii) 三要求之②):遗留证明的签署 pk 必须被一个不可变前态绑定,防事后伪造/替换。
4. **版本进摘要**(同③要求):`legacy_fee_attestation` 的 schema 版本 + cutover_daa + 两个常量值 + 域分隔 tag 全进 blake2b 摘要;摘要即授权承诺。
5. **单调封闭**: 承诺后**不得追加**(遗留集只减不增);任何"扩集"= 新证明 = 重新红队。

## §3 候选 A 如何消费(判据,机械可测)
对一笔待签结算,候选 A 求该市场费率权威:
- **新市场(created ≥ cutover_daa)**: 权威 = redeem-ctor(走 (i)),(甲) 不参与。
- **存量市场(created < cutover_daa)**: 权威 = `legacy_fee_attestation` 谓词常量;须同时满足 (i) 的**逐入口**要求的对等物 —— 见 §4。
- **两条都取不到 ⇒ inconclusive 不签**(保持 R-3.3 fail-closed,(甲) 不弱化)。

## §4 与 (i) 四条 DoD 的对齐(承重,防 (甲) 变成绕过 (i) 的软口)
(甲) 给存量的是**费率【值】的权威**,不豁免 (i) 证过的其它约束:
- 🔴 **逐入口仍适用**: 存量盘的实际结算走的还是那份烤死 covenant——而 J2 R-4 已证 **v0.7 covenant 对 minerFee 是惰性的、dispute/refund 两入口对费率零约束**。⇒ **(甲) 只能授权"费率值是这个常量",【不能】声称"结算实际用了这个费率" —— 后者存量 covenant 本就不强制。** 这条必须写进 (甲) 的覆盖边界(同 §0 已知不覆盖项的做法),否则 (甲) 会把"知道费率名义值"误报成"费率被强制"。
- **⇒ 存量盘的费率【强制】维度,(甲) 明确标为 NOT-COVERED**,压到 §7-1 人工出口 or 单独裁 —— 这是 (甲) 与 (i) 的真实差距:(i) 新盘能做到"编进+强制+逐入口",(甲) 存量只能做到"值有权威",强制维度存量补不回来(covenant 烤死)。**如实标死,不假装存量能和新盘等价。**

## §5 DoD(红队验收)
1. 谓词 + cutover_daa 摘要机械可复验(离线重算 == 承诺值)。
2. cutover_daa 权威非自证(指得出独立锚)。
3. 阴性对照: 改两个常量值任一 → 候选 A 对存量盘读数变(证明它真消费了这个证明,不是恒真)。
4. 覆盖边界诚实: §4 的"值有权威 ≠ 强制被执行"逐字写入,存量强制维度标 NOT-COVERED。
5. 封闭性: 无"追加遗留市场"通道(扩集必经新红队)。
