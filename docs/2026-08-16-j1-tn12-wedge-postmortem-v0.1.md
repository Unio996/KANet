## 根因分层（按证据强度）
1. **直接原因（实测）**：熔断器 v1 进程死亡后无人重启。矿（stratum-bridge → 本机 kaspad）持续产块，tips 突破 248 悬崖进入楔死——tips 3302、DAA 冻结在 77,096,1xx、两独立节点同高度（本机 via 公网 peer 同看）。
2. **结构原因（(263) Bettor 钉）**：**v2 熔断 watchdog 建成后从未接进 boot card**——三次开机 dispatched 的都是 v1。"teeth built, not armed" 族的又一实例（与 VOTER 那条 memory 同族）：**建了仪器 ≠ 有守卫，接进开机卡才算**。boot card 是"实际会跑什么"的单一真相源，它没改=什么都没变。
3. **放大器（实测）**：远程观测路**单一化**——第二源交叉核、SSH、发送器送达自证全部骑在同一条 Tailscale 上；它死=全部盲。备用路（RustDesk 中继）在册但被标"交互卡顿不用"——**作为探针它完全够用**，这次正是它破的局。
4. **诊断修正链（自记）**：J1 (261) 曾判"机器本体离线三选一"；操作员两条现场判据（有电/摄像头回画面）连续砍掉两支——**带外仪器（摄像头）是本次最便宜且决定性的探针**。
