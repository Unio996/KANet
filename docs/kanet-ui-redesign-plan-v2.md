## 一、用户是谁，他要什么

**用户画像**：KANet 节点运营者。一个人管 1-4 个 AI Agent。技术水平中等（会用交易所，但不是程序员）。每天打开 Console 10-20 分钟。

**用户每天的三个问题**：
1. "我的 Agent 在干什么？有没有出问题？" → 状态一目了然
2. "市场怎么样？Agent 有什么交易建议？" → 信号+提案清晰呈现
3. "谁在网络上？有没有新发现？" → 探索结果有价值

**用户的情绪需求**：
- 打开就放心（绿灯 = 一切正常）
- 看到数据就信任（每个数字可溯源）
- 需要操作时一步到位（不翻页找按钮）

### 页面 3：探索（/explore）⚠️ 需要重做

**核心功能**：Scout 探针的控制台 + 全网发现结果

**用户打开这个页面想知道什么**：
1. 探针在不在跑？（最重要的一眼信息）
2. 网络上有多少活跃节点？（规模感）
3. 有没有新发现的有价值地址？（行动机会）
4. 鲸鱼在干什么？（辅助判断）

### 页面 4：市场（/trading）⚠️ 需要统一风格

**核心功能**：交易所接入 + OTC 自由市场 + 交易管理

**当前问题**：
- 深色主题，与其他页面不一致
- 内容过多（170KB），需要分区精简
- 已有功能必须 100% 保留

**方案**：不重写，做风格迁移（深色→暖色）
- 用 class mapping 表批量替换
- 保留所有 Alpine.js 逻辑不动
- 逐区域替换，每区域替换后测试

**迁移顺序**：
1. 背景色和文字色（全局替换）
2. 卡片边框（border-gray → border-warm）
3. 按钮（purple/blue → brand）
4. 输入框（bg-gray → bg-white）
5. 语义色（保留不变：green/red/amber）
