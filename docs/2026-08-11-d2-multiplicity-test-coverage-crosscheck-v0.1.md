## §2 🔵 机制(为什么会这样 —— 不是"漏写断言")

唯一使用 V2 的那格 `T2_v2` 构造了 **2 个 covOuts** ⇒ **N1 先拒并早退** ⇒
其后的 SPK 循环与 value 检查**根本走不到**。

⇒ **V2 的 SPK / value / 零闸是被这份用例【结构性够不到】的**,不是断言写漏。
⇒ **补法不是加断言,是加输入形状**:
  1. 一格 **只有 1 个 covOut 且 value 不符** ⇒ 应命中 N3;
  2. 一格 **只有 1 个 covOut 且 spk 不符** ⇒ 应命中 SPK 绑定;
  3. 一格 **零 covOut 走 V2** ⇒ 应命中 V2 的零闸;
  4. 一格 **完全合法** ⇒ `ok:true` 阳性对照(挡恒拒型装饰)。
