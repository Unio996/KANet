## §3 🔴 对 v0.2 §2 的一处更正:`dim5_fail_recovery_04` 应从 🔵 挪到 🔴

v0.2 §2 该行「伴随断言 = ✅ 有 ⇒ 🔵 干净」。**逐字读它的伴随断言**:

```
sql: SELECT count(*) AS c FROM pragma_index_list('exchange_offers') …
expect: { must: { row_assert: { c_min: 1 } } }
```

⇒ 它量的是 **`pragma_index_list`,不是数据表**。**空库实测 = 8** —— 索引在 schema 里,库空它照样成立。
⇒ **它是「机制存在」证明,不是「总体非空」证明。**

🔴 **而 v0.2 自己在 §3.1 对 `dim6_race_01` 划过的正是这条线**
(逐字:「它带了一条伴随断言, 但方向是"机制存在"不是"总体非空"」)。
**同一个形状,一个抓到了,它的双胞胎没抓到** —— 因为 §2 那张表的「伴随断言」列填的是**有没有**,
不是**是哪一种**。

🔨 **判据(本稿主要产出)**:
> **「有伴随断言」不是一个判定。判定必须是「伴随断言在被测总体为空时是否为假」。**
> 前者可以靠看一眼填表,后者只能靠**把它代进空库跑一次**。
> 一张按「有没有」填的表,会把两种东西并到同一格,而它们的读数正好相同。
