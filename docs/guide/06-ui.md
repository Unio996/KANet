## 六、UI 组件系统

### 技术栈

Fastify + Eta 模板 + Tailwind CSS + Alpine.js

### 新页面 boilerplate

```html
<%~ include('partials/page-open', { _page: 'mypage', pageTitle: '标题', ...it }) %>
<div class="p-6" x-data="{ }">
  <!-- 内容 -->
</div>
<%~ include('partials/page-close', it) %>
```
