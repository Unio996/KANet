## 1. `/tokens/create` — 代币创建

依赖：`POST /api/tokens/create`（J2）

| 步骤 | 操作 | 期望 |
|---|---|---|
| 1.1 | 打开 `/tokens/create` | 页面 200，标题"创建代币"，出单人下拉里出现真实 relay 列表（主网库 17 个 relay，非"没有可用的出单人"） |
| 1.2 | 不填任何字段直接点「创建代币」 | 按钮 disabled（灰态），不发请求 |
| 1.3 | 只选出单人 + 填数量，留空名称/ticker | 按钮仍 disabled |
| 1.4 | 全部必填字段填好（出单人/数量>0/名称/ticker），点「创建代币」 | **若端点未上线**：按钮变"创建中..."后恢复，出现红色错误条"创建失败: HTTP 404（后端接口尚未上线）"，表单字段保留原值不清空。**若端点已上线**：跳转完成态，显示 ✓ + TX 摘要 + 「查看代币列表」/「再造一个」两个按钮 |
| 1.5（端点已上线时） | 点「查看代币列表」 | 跳到 `/tokens`，能看到刚创建的这一条 |

## 2. `/tokens` — 代币列表

依赖：`GET /api/tokens`（J2）

| 步骤 | 操作 | 期望 |
|---|---|---|
| 2.1 | 打开 `/tokens` | **未上线**：红色"加载失败：HTTP 404（后端接口可能尚未上线）"。**已上线、无数据**：空态"还没有创建过代币" + 「创建第一个 →」。**已上线、有数据**：表格显示 名称/ticker/发行量/出单人/创建时间 |
| 2.2 | 点右上角「创建代币 →」 | 跳到 `/tokens/create` |

## 3. `/proto-markets/create` — 市场创建

依赖：`GET /api/tokens`（选代币用，J2）、`POST /api/proto-markets/create`（J2）

| 步骤 | 操作 | 期望 |
|---|---|---|
| 3.1 | 打开 `/proto-markets/create`，此时 `/tokens` 还没有任何代币 | 结算代币下拉只有"选一个代币..."一项，下方提示"还没有代币，先去创建一个"（链接到 `/tokens/create`） |
| 3.2 | 已有代币后重新打开本页 | 下拉列出真实代币（`名称 (ticker)` 格式） |
| 3.3 | 只选代币，留空标题/截止时间，点提交 | 按钮 disabled |
| 3.4 | 代币+标题+截止时间填好，点「创建市场」 | 同 §1.4 的成功/失败两态逻辑 |

## 4. `/proto-markets` — 市场列表

依赖：`GET /api/proto-markets`（J2）

| 步骤 | 操作 | 期望 |
|---|---|---|
| 4.1 | 打开 `/proto-markets` | 未上线/空/有数据三态同 §2.1 的逻辑（图标🎲，文案"还没有市场"） |
| 4.2 | 有数据时点某一行「详情 →」 | 跳到 `/proto-markets/:id` |

## 5. `/proto-markets/:id` — 市场详情（下注 + 宣布结果 + claim 合一页）

依赖：`GET /api/proto-markets/:id`、`POST .../bet`、`POST .../resolve`、`POST .../claim`（均 J2）

按市场当前 `status` 走不同分支，建议 J2 后端上线后手工造 4 条不同状态的市场各点一遍：

| 市场状态 | 应该看到的面板 | 点验动作 | 期望 |
|---|---|---|---|
| `open` | 下注面板 + 出单人宣布结果面板 | 选 YES/NO + 填数量 → 提交下注 | 成功：绿色"下注成功，TX: ..."；失败：红色错误，如实显示 |
| `open`/`closed` | 出单人宣布结果面板 | 点「判 YES 赢」或「判 NO 赢」 | 成功后提示"已宣布，刷新页面查看最新状态"；非出单人调用应看到后端拒绝的错误文案（前端不做权限判断，只透传） |
| `resolved` | 领取面板，显示"结果：YES 赢 / NO 赢" | 点「Claim」 | 赢家：绿色"Claim 成功，TX: ..."；非赢家/已 claim：如实显示后端错误 |
| `refunded` | 领取面板，显示"到期无人宣布结果，全员退款" | 点「Claim」 | 退款到账提示或如实错误 |
| 不存在的 id | — | 直接访问 `/proto-markets/does-not-exist` | 红色"加载失败：HTTP 404（后端接口尚未上线，或该市场不存在）" |
