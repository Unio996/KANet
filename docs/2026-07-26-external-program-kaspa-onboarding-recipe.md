## 🔴🔴 2026-07-27 晨:**"外部"这个词一直在滑动着用,而三层的门槛差一个数量级**

昨天这份记录写「一个外部程序完整走通了发送侧」。**那句只对最容易的那一层成立。**

| 「外部」是哪一层 | 状态 |
|---|---|
| **不用我们的身份/密钥** | ✅ 已实证(两个 txid) |
| **不在这台机器上** | ✅ 已实证(J1 经 tailnet 连通我们的 `3210` / `17210`) |
| ✅ **不在我们这张网里的任何人** | ✅ **2026-07-28 已实证**(~~这一层今天走不通~~ 已过期)。见下方订正 |

🔴 **⇒ J2 那两笔的 RPC 端点是 `ws://127.0.0.1:17210`(本机回环)。**
✅ **2026-07-28 订正(J1 本人给的,替换原来那句「J1 走的是 tailnet」)**:
> **J1 这台 tailnet 可达,但那只用于【带外只读探测】;它的 kaspad 走的是公网 P2P。**
> 判据用定义不用相关性:「怎么接进 TN12」= 它的 P2P 出向连到哪,不是「这台有没有开 tailscale」。
> J1 全日志去重后的 P2P peer 全集恰好 2 个,都在公网段,**tailnet 网段命中 0**(含压缩历史日志)。
>
> 🔵 **第二路独立佐证(KANet-UI,live kaspad RPC)**:我们这台当前 2 个 peer **就是 J1 连的那两个确切地址**,且**两个都是我们向外拨出**(`is_outbound=true`),**入向 peer 数 = 0**。
> ⇒ 一个节点不会把自己的公网出口当远端 kaspad peer 拨出去还被对面应答 ⇒ **那两个 IP 是第三方节点,不是我们**。
> ⇒ 原先「J1 会不会其实是绕回我们家」这一格**已关闭**;那笔探针跨的是**第三层**。
🔨 **⇒ 落一条:凡写「外部 / 对外 / 外面的人」,必须同时写清【相对于什么的外部】。三者不能共用一个词。**

### ✅ 而「外面的人根本没有入口」这句也是错的(同晨修正)

- ✅ **实测**:我们的节点**此刻**连着**两个公网 IP** 的 TN12 对等节点,且是**发现来的**(配置零命中、命令行无 `--addpeer`),**并且都不是自己人**(J1 已核他的出口 IP 与两者皆不同)。
- 🔴 ⇒ **「TN12 上几乎不可能有别的节点」——确凿地假。**
- ⚠️ **而 `16311` 是 P2P 口,不是 RPC** ⇒ **「有别的公网节点」≠「外部程序能通过它们广播」**,后者**未验,且不去验**(那是对外主动连接)。
- ✅ **所以唯一站得住的是**:**外面的人连不到【我们这台】** —— 因为我们在公网上没有地址。**而他能不能通过别人的节点进来,不知道。**

### 🔴 而「要不要给这台机器一个公网入口」不是一次测量,是一个未做的决定

我们在 NAT 后面,没做过端口转发 ⇒ **不是被挡住,是没有入口**。
⚠️ **而两个我们用来测的地址(一个内网 `192.168.x.x` · 一个 tailnet `100.x.x.x`,具体值不写在公开文档里)在公网上都不存在** ⇒ 拿它们做的任何"从外面连"的测试**必然失败,而失败原因与被测的那一层无关**。🔵 又一次:**一个失败,长得像答案。**

## 二、🔴🔴 四个坑 —— 报错**一字不差**,而其中一个外部**不可能自己发现**

**四种完全不同的写错,输出全部是:`RuntimeError: unreachable` + 一串纯地址栈,不提任何参数名。**

| # | 坑 | 正确写法 |
|---|---|---|
| 1 | 🔴 `networkId` 传我们**实际的网络名** `'testnet-12'` | **必须传 `'testnet-10'`**。【实读】`wallet.mjs:95-98` 有这个内部映射 |
| 2 | `payload` 传 hex 字符串或 `Buffer` | **必须 `Uint8Array`** |
| 3 | `outputs` / `changeAddress` 传字符串 | **必须 `PaymentOutput` / `Address` 对象** |
| 4 | 用 `createTransactions()` | **必须 `new Generator()`** |

🔴 **第 1 条是这份文档存在的核心理由**:一个外部的人**没有任何途径**能猜到"网络叫 testnet-12 但要填 testnet-10" —— 那是我们代码里的一个映射。而他填对了真名字,拿到的是一句什么都不说的报错。

🔵 **⇒ 这是「失败不产生失败,产生一个形状正确的答案」在最伤外面人的地方的实例**:四个不同原因,一个相同的、零信息的输出。**把这四格写下来,它们就不再是坎。**
