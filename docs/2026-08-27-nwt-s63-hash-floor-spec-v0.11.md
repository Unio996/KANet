## 钉 `W_min = 3600 s`（法3′ 接收计窗下限）

法3′ 已把按戳定窗的死带归零 ⇒ `W_min` 不再由"死带占窗比例"定（那是 v0.9 `×W/(W−264)` 的理由，v0.10 已作废）。现由**两条**定，`3600 s` 同时满足且有裕度：

1. **样本量足够使泊松单侧上分位紧**：TN12 `10 BPS` ⇒ `n = BPS × (t1−t0) = 10 × 3600 = 36,000` 块；`σ = √n ≈ 189.7`；单侧 99.9%（`z=3.09`）放大 = `3.09σ / n = 586 / 36,000 ≈ +1.6%`。⇒ ub 的统计余量仅 +1.6%，窗越长越紧（`W_min` 是**下限**，更长允许、更保守）。
2. **`T_prop ≪ (t1−t0)`**：传播时延秒级，`3600 s` 下"`[t0,t1]` 内造、`t1` 后到"的欠计残差 `T_prop/(t1−t0)` = 秒/3600 ≈ 0.x% 可忽略。

> 🔴 **`600 s` 不合格的原因已随 v0.10 变化**：v0.9 用 `600 s` 撞 `×W/(W−264)=1.786` 爆炸；法3′ 无此项，但 `600 s` 下 `n=6,000`、分位放大 `+4%`、且 `T_prop/600` 更显著 ⇒ 仍取 `3600 s` 为下限，理由从"死带"迁移为"样本量 + `T_prop` 占比"。

**落点（覆盖 v0.10 里"须具名一个数"两处）**：
- **§3.5(b) 改点3 硬闸**：`(t1−t0) < 3600 s ∨ 未取分位（单侧 99.9%, n_ub = n + 3.09√n）∨ H_self_lb > H_vis_ub ∨ 无 B_adv ⇒ (b) 不出 cap ⇒ 回 (a-total)`。
- **§8-4**：`H_vis_ub` = 法3′（本机时钟接收计数 + 泊松单侧 99.9% 上分位，**`(t1−t0) ≥ 3600 s`**）或法2（接收基/加 red work）；不许按块戳定窗（MUST-B）、不许 `max(三法 raw)`/法1 单用（方向反）。
