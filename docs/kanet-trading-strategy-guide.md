# KANet 交易系统 — 策略架构与使用指南

> 版本：v1.0 | 2026-03-30
> 适用：KANet Console + Agent Mind 交易系统

---

## 一、系统架构总览

KANet 的交易系统是四层架构，每层各司其职：

```
数据层（已实现）
  交易所实时数据：价格、K线、订单簿、成交量
  链上数据：鲸鱼转账、网络活动
  ↓
信号层（signal-engine.js）
  原始数据 → 五维量化信号 → 综合评分
  纯数学，不用 AI，确定性计算
  ↓
策略层（strategy-engine.js）
  信号 + 市场环境 + 账户状态 → 交易提案
  纯逻辑，规则引擎，不用 AI
  ↓
决策层（Brain / AI）
  收到结构化提案 → 常识审批（ACCEPT / REJECT）
  不自由发挥，不发明交易，只做最后一道判断
  ↓
执行层（trade-executor / exchange-orders）
  下单 → 记录 → 反馈闭环
```

**核心原则**：能用规则算的不用 AI。AI 只做最后的常识判断。

## 二、锚定模式（最重要的设置）

### 什么是锚定？

锚定决定了交易系统的根本目标 — "赚什么"。

### 法币锚（USDT）

```
目标：增加 USDT 价值
KAS 是资产，USDT 是目标
卖出 KAS = 落袋为安
持有 KAS = 承担风险敞口
```

适用场景：
- 你认为 KAS 价格可能下跌
- 你需要稳定的法币收益
- 短线交易为主

### 本币锚（KAS）

```
目标：增加 KAS 持有量
KAS 是目标，USDT 是弹药
卖出 KAS = 动用弹药（在高点换成 USDT，等低点买回更多 KAS）
USDT 不是利润，是等待买回的中间状态
```

适用场景：
- 你长期看好 KAS
- 大周期上升阶段
- 目标是囤更多币

### 锚定如何影响交易决策

同一个市场信号，两种锚完全不同的操作：

| 市场信号 | 法币锚操作 | 本币锚操作 |
|---------|-----------|-----------|
| 价格下跌 | 止损卖出保 USDT | 用 USDT 弹药抄底买 KAS |
| 价格上涨 | 持有或加仓 | 高点卖出部分换弹药 |
| 横盘震荡 | 网格交易赚 USDT 差价 | 不动，等趋势明朗 |

### 设置方法

打开 `/trading` → 设置区域 → 右上角"锚定"按钮切换

## 三、五维信号体系

信号引擎从交易所实时数据计算五个维度的信号，每个信号范围 -100 到 +100：

### 1. 趋势信号（权重 30%）

```
计算方法：EMA9 / EMA21 交叉方向 × ADX 趋势强度
正值 = 看涨趋势（EMA 金叉 + 趋势强）
负值 = 看跌趋势（EMA 死叉 + 趋势强）
接近 0 = 趋势不明
```

EMA（指数移动平均线）是价格的平滑曲线。短期 EMA 上穿长期 EMA = 金叉（看涨），反之 = 死叉（看跌）。ADX 衡量趋势的强弱（>25 = 强趋势，<20 = 没趋势）。

### 2. 动量信号（权重 25%）

```
计算方法：(RSI 偏离度 + MACD 柱状图 + ROC 变化率) / 3
正值 = 上涨动能强
负值 = 下跌动能强
```

三个子指标分别衡量超买超卖（RSI）、趋势加速度（MACD）、价格变化速率（ROC）。

### 3. 订单流信号（权重 25%）

```
计算方法：(买盘深度 - 卖盘深度) / (买盘 + 卖盘) × 100
正值 = 买方力量强
负值 = 卖方力量强
```

这是最接近"真实买卖意愿"的信号。看的是交易所订单簿前 20 档的挂单量对比。

### 4. 波动率信号（0-100，不参与综合评分）

```
计算方法：Bollinger Band 宽度
> 80 = 极端波动，触发熔断
> 60 = 高波动
< 30 = 低波动
```

波动率不直接影响"买还是卖"，但影响是否应该交易。极端波动时暂停。

### 5. 鲸鱼信号（权重 20%）

```
来源：Kaspa 链上大额转账监控
正值 = 鲸鱼在累积（买入）
负值 = 鲸鱼在派发（卖出）
```

链上信号是交叉验证，不是主要交易触发。它辅助确认交易所信号的可信度。

### 综合评分

```
综合评分 = 趋势×0.30 + 动量×0.25 + 订单流×0.25 + 鲸鱼×0.20
置信度 = 信号一致性（全看涨=1.0，互相矛盾=0.25）
可操作性 = |综合评分 × 置信度| > 60
```

**只有可操作性为 true 时，策略层才生成提案。** 这确保 Agent 不会在信号不够强时冲动交易。

## 四、市场环境识别

策略引擎根据 ADX 值自动判断当前市场处于什么状态：

| ADX 值 | 市场环境 | 适用策略 | Agent 行为 |
|--------|---------|---------|-----------|
| > 25 | 趋势市（trending） | 趋势跟踪 | 顺势而为 |
| < 20 | 震荡市（ranging） | 网格/均值回归 | 高抛低吸 |
| 20-25 | 不确定（uncertain） | 无 | 观望不动 |

**市场环境识别是最高杠杆的判断。** 用错策略比用错入场点更致命 — 在趋势市做网格会爆仓，在震荡市追趋势会来回打脸。

## 五、策略模板

### 法币锚策略

#### 趋势跟踪

```
触发条件：趋势市 + 可操作信号
逻辑：综合评分 > 0 → 买入，< 0 → 卖出
仓位：2% 资产
止损：-3%
止盈：+6%（盈亏比 1:2）
```

#### 网格交易

```
触发条件：震荡市 + 波动率 > 20
逻辑：价格低 → 买，价格高 → 卖
仓位：1% 资产
无止损止盈（依赖网格边界）
```

#### 均值回归

```
触发条件：动量信号 > 70（超买）或 < -70（超卖）
逻辑：超买 → 卖，超卖 → 买（反向操作）
仓位：1% 资产
止损：-4%
止盈：+3%
```

### 本币锚策略

#### 低吸囤币

```
触发条件：信号看跌 + 有 USDT 弹药
逻辑：价格跌了 = 便宜了 = 买入机会
动用 30% USDT 弹药买 KAS
无止损（跌了更便宜 = 更好）
```

#### 高抛备弹

```
触发条件：信号看涨 + 趋势市 + KAS 充足
逻辑：价格涨了 → 卖出 1% KAS 换 USDT 弹药
等回调时用弹药买回更多 KAS
预估净增 KAS = 弹药/低价 - 卖出量
```

#### 回调补仓

```
触发条件：之前高抛过（有 USDT）+ 动量转弱
逻辑：动用 50% USDT 弹药买回 KAS
目标：买回的 KAS > 当初卖出的 = 净增
```

## 六、风险管理

### 仓位控制

| 规则 | 值 | 说明 |
|------|---|------|
| 单笔最大 | 资产 2% | 四分之一凯利，硬上限 |
| auto 模式限额 | 200 KAS / 20 USDT | 新手限额，验证能力后可调 |
| 日交易限额 | 5000 KAS / 500 USDT | 防止一天内过度交易 |

### 三档熔断

| 级别 | 条件 | 动作 |
|------|------|------|
| 黄灯 | 日亏损 ≥ 5% | 仓位自动减半 |
| 红灯 | 日亏损 ≥ 10% | 停止所有交易 |
| 冻结 | 总回撤 ≥ 15% | 冻结交易，等待 Owner 人工确认 |

### 波动率熔断

当波动率信号 > 80（极端波动，通常对应重大市场事件），暂停所有交易。

### 信号阈值

综合评分 × 置信度 < 60 → 不生成提案 → Agent 不交易。这是最重要的一道门 — 没有足够强的信号就不动。

## 七、Agent 交易模式（per-agent）

每个 Agent 可以单独设置交易权限：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **禁止** | 完全不允许交易 | 非交易用途的 Agent |
| **手动** | 只有 Owner 能操作 | 完全人工控制 |
| **批准** | Agent 发起，Owner 确认 | 学习阶段，人机协作 |
| **自动** | 限额内自主交易 | Agent 已证明能力后 |

### 设置方法

打开 `/trading` → 设置区域 → 每个 Agent 一行，四个按钮独立切换

### 建议的渐进式放权路径

```
第一周：全部 → 批准模式
  观察 Agent 提出什么样的交易提案
  判断其信号解读和时机选择是否合理

第二周：表现好的 → 自动模式（限额 200 KAS）
  让 Agent 小额验证
  观察实际盈亏和风控表现

第三周+：验证通过 → 逐步提高限额
  auto_mode_max_kas 从 200 → 500 → 1000
  始终不超过 per_order_max 的 30%
```

## 八、交易提案格式

当信号足够强（actionable=true），Agent 收到的提案格式如下：

### 法币锚提案示例

```
=== TRADING PROPOSAL ===
Strategy: 趋势跟踪（法币锚）
Anchor: 法币锚（目标增值USDT）
Signal: 72/100 (confidence 85%)
Regime: trending (ADX=32)
Action: SELL 200 KAS @ $0.0345
Stop-loss: $0.0360 (max loss: 3.00 KAS)
Take-profit: $0.0325
Reason: 趋势看跌(EMA死叉) + 卖盘压力(OBI=-40) + ADX=32(强趋势)

Risk Assessment:
Position: 2.00% of portfolio
Max loss: 3.00 KAS
Daily: 0/5000 KAS
```

### 本币锚提案示例

```
=== TRADING PROPOSAL ===
Strategy: 低吸囤币
Anchor: 本币锚（目标增持KAS）
Signal: -65/100 (confidence 75%)
Regime: trending (ADX=38)
Action: BUY 600 KAS @ $0.0325
Stop-loss: none (本币锚不设)
Take-profit: none
Reason: 趋势看跌(EMA死叉) + 买盘压力(OBI=36) + ADX=38(强趋势) + [本币锚：目标增持KAS]

Risk Assessment:
KAS at risk: 600 KAS
USDT deployed: 19.50 USDT
Daily: 0/5000 KAS
```

### Agent 的决策

Agent（Brain/AI）只能做两件事：

1. **ACCEPT** → 执行提案中的参数，不修改
2. **REJECT: [理由]** → 不执行，记录拒绝原因

Agent 不能自己编造交易、修改参数、或在没有提案时下单。

## 九、执行记录与反馈闭环

### 每笔交易完整记录

```
execution_states 表记录：
  strategy      ← 用了哪个策略（trend_following / accumulate / ...）
  signal        ← 当时的综合评分和置信度
  regime        ← 当时的市场环境
  action        ← buy / sell
  amount        ← 交易数量
  price         ← 成交价格
  stopLoss      ← 止损价
  takeProfit    ← 止盈价
  reason        ← 信号原因（完整文本）
  brainDecision ← Agent 的决策（ACCEPT / REJECT + 原因）
  outcome       ← 最终结果（事后填入）
  pnl           ← 实际盈亏（事后填入）
```

### Episode 反哺

交易完成后，episode-builder 将交易聚合为故事线。下次 Agent 反思时，Brain 能看到：

```
--- TRADE PERFORMANCE (last 7 days) ---
50 trades: 17 completed, 0 disputed, 33 cancelled
Total volume: 279 KAS
Chains used: BNB(50)

--- COUNTERPARTY RELIABILITY ---
  Sophie: 17 completed, 279 KAS, 0 disputed
```

Agent 根据历史表现调整策略偏好：
- 哪些策略赚钱了？
- 哪些对手方可靠？
- 哪种市场环境下表现最好？

## 十二、Sophie 案例复盘

### 改造前

```
Sophie 的行为：
  目标："执行一笔小测试交易"
  每 15 分钟 proactive 循环
  → Brain 看到目标 → 焦虑 → 提交 SELL 1000 KAS
  → 没有综合信息分析评判依据提交，没有止损
 

问题：目标驱动，不是信号驱动
```

### 改造后

```
Sophie 的行为：
  信号引擎计算：composite=-16, confidence=0.25, actionable=false
  → 不生成提案
  → trade-sense 告诉 Brain："没有可操作信号，别动"
  → Sophie 不焦虑，去做社交、学习、观察

  如果信号变强：composite=72, confidence=0.85, actionable=true
  → 策略引擎生成提案：低吸囤币，买 600 KAS @ $0.0325
  → Brain 收到结构化提案，只做 ACCEPT/REJECT
  → 模式=auto → 自动执行
  → execution_states 完整记录策略、信号、理由
  → Episode 反哺下次反思
```

**从"冲动交易者"变成"纪律投资者"。**

## 十三、未来扩展

### 数据源接入（管道已有，内容待丰富）

- 预测市场（Polymarket API）
- 股票/大宗行情数据
- 新闻舆情信号
- 社交媒体情绪

每多接一个数据源，信号维度就多一个，Agent 的分析能力随之增长。

### 策略进化

- Agent 根据历史表现自动调整策略权重
- 回测框架：用历史数据验证策略有效性
- 多 Agent 策略对比：谁的策略更赚钱？

### 自由市场

当 KANet 节点超过 1000，链上 OTC 自由市场才有流动性。届时：
- 信号引擎同时分析交易所 + 自由市场价差
- 跨市场套利机会
- Agent 之间的策略竞争和协作
