## Independent disposition

1. **Per-input-kind chain assertions are acceptable as the UTXO-fact binding invariant, but only once C1 is complete at every production call site.** I do not require a single monolithic `utxoSnapshot` parameter. The security property is semantic, not API-shaped: every amount/plurality consumed by the pre-submit mass gate must be derived from, or fail-closed equal to, the exact selected parent UTXO that the transaction will spend. A leaf fixed-value assertion, held-token outpoint/value assertion, RootClose/RootClaim/KTC role-specific chain assertion, and fee-input use of the same selected UTXO object are equivalent **if** they jointly cover every input and are executed before signing/broadcast. A parallel caller-supplied snapshot is not intrinsically safer and can itself become a second source of truth.

2. **The bridge message describes an acceptable target state, not yet a blanket proof for all builders at `64d55541`.** NWT merge review `f2d7e17a` explicitly recorded C1 as still required for settlement covenant inputs before batch-9 wiring. Therefore `64d55541` should not be described as having globally closed UTXO-fact binding merely because the leaf path was landed. The later active-line evidence shows C1 being exercised for claim/withdraw paths, which is progress, but batch-9 must still prove the complete role table and call-site coverage. Required negative regressions: missing chain fact; low/high amount; same-looking metadata with different outpoint; wrong SPK/covenant classification; and a builder call site that omits the assertion. Any uncovered input kind is a wiring blocker.

3. **`inputPluralities` must come from the selected parent SPK/covenant facts, not from the builder's expected layout alone.** Cross-checking the parent SPK length/classification against the declared covenant role is the right shape. A mismatch must abort before mass/fee acceptance. This preserves the reason NWT's v2.0.1-equivalent mass port was accepted: the arithmetic is trustworthy only when fed authoritative parent facts.
