## 根因

## 修法 (~5 LOC NWT broker-action-queue.js)

executeAction 内 dm_* kind retry 时 re-tag:
```js
case 'dm_quote': case 'dm_pay_instr': case 'dm_completion': case 'dm_position': {
  // T-NWT-14: pump 每次 attempt re-tag (T-J2-15 cross-session tag + 此处 retry tag 双解)
  const baseMsg = item.payload.message.replace(/\s*#[a-f0-9]{4}\s*$/, '');
  const reTagged = baseMsg + ` #${randomUUID().slice(0,4)}`;
  return sendCommandAsync(BROKER_RELAY_ID, { type:'send_message', target:item.peer, message:reTagged });
}
```
