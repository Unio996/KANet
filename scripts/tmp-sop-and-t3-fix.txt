### Bug #4: extractJson 从 reasoning_content 里抓不到完整 JSON
reasoning_content 是英文推理 3000 字, 内嵌多个 {...} 片段. 当前 extractJson 用贪婪正则 `\{[\s\S]*\}` 会抓最外层包括错格式的 JSON 造成 parse fail.

改 extractJson (dialog.js 层): **找最后一个 { 开始到最后一个 } 为止**的片段 (通常 LLM 最终答案在末尾), 或者**匹配所有 {...} 片段挨个 parse 取第一个有效的**.

或者在 retail-dex-memory.js 本地做:
```js
// 从 reasoning 文本末尾抓 JSON
function extractLastJson(text) {
  if (!text) return null;
  // 尝试找 ```json ... ``` 代码块
  const fenced = text.match(/```json\s*([\s\S]*?)```/);
  if (fenced) try { return JSON.parse(fenced[1]); } catch {}
  // 否则抓最后一个 {...}
  const matches = [...text.matchAll(/\{[^{]*?\}/g)];  // 非嵌套简单 JSON
  for (let i = matches.length - 1; i >= 0; i--) {
    try {
      const obj = JSON.parse(matches[i][0]);
      if (obj && typeof obj === 'object') return obj;
    } catch {}
  }
  // 最后 fallback 贪婪
  const greedy = text.match(/\{[\s\S]*\}/);
  if (greedy) try { return JSON.parse(greedy[0]); } catch {}
  return null;
}
```
在 _parseDistillResult 里用 extractLastJson 代替 extractJson. 或在 dialog.js 升级 extractJson.
