## 非托管完整链路

DM 入口 → handleDm → selectBestOffer+computeQuote (读 Maker 地址)
→ YES → broadcast accept_v1 (receive_address=user_kasia)
→ exchange-machine routeToVerification (auto-pay gate 跳过 DEX broker)
→ user 自行付 USDT 给 Maker BSC 地址
→ user 回 tx hash → broadcast paid_v1 (payment_tx=user tx)
→ exchange-machine.handleExchangePaid verify (sender 不校验, confirm)
→ Maker 自动发 KAS 到 receive_address (用户 Kasia 地址)
→ offer.protocol_status=completed
→ order.completed + delivery_tx

Broker 零 USDT 流经, 零 KAS 中转, 只上链发两条协议广播.
