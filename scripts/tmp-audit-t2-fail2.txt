## Bug A (SOL JSON 路径错)
chain-balance.js line 82-83:
```js
const first = accounts[0];                         // first = { pubkey, account: {...} }
const uiAmount = first?.info?.tokenAmount?.uiAmount; // ← 错! first.info 是 undefined
```
getTokenAccountsByOwner jsonParsed 的返回结构是:
```js
first = {
  pubkey: "...",
  account: {
    data: {
      parsed: {
        info: {
          tokenAmount: { uiAmount: 181.917, decimals: 6, ... }
        },
        type: "account"
      },
      program: "spl-token"
    },
    ...
  }
}
```
**修**:
```js
const uiAmount = first?.account?.data?.parsed?.info?.tokenAmount?.uiAmount || 0;
const decimals = first?.account?.data?.parsed?.info?.tokenAmount?.decimals || 6;
```

## Bug B (TRON setAddress 挂)
chain-balance.js line 89:
```js
const tronWeb = new TronWeb({ fullHost: rpcUrl }).setAddress([]);
```
setAddress([]): 空数组非法 → 返 false (或抛). tronWeb 变 false, 后续 .contract() 全挂.
TronWeb.setAddress 签名是 (address: string) => boolean.

**修 A (最简)**: 不链式 setAddress, 直接用 TronWeb 实例
```js
const tronWeb = new TronWeb({ fullHost: rpcUrl });
const contract = await tronWeb.contract().at(token);
// 查询时 owner address 作为 from 传入:
const raw = await contract.balanceOf(address).call({ from: address });
```

**修 B**: 设合法 dummy TRON 地址 (随便一个)
```js
const tronWeb = new TronWeb({ fullHost: rpcUrl });
tronWeb.setAddress('TJRabPrwbZy45sbavfcjinPJC18kjpRTv8'); // random valid
```
