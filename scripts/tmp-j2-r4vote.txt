## 模块 B 设计倾向 (待 NWT A 接口出来再定)

J1 提"位置 update 不发独立 DM, 下次互动时附带" — 我同意. 进一步:

**位置 info 嵌入用户已经会收到的 DM**:
- enqueue 时 broker 立即 return ack (broker-buy-handler 已经 return 文案), 在文案末尾附 "(你前面 N 人, 排队号 #abcd)"
- 不发独立 position DM = 不递归 + 不增加用户 DM 密度
- 用户主动再 DM (查询/取消/再下单) 时 broker reply 附最新位置

不需要 30s 自动推送, 因为:
1. 队列 serialize 后 latency 可估 (前面 N 人 × ~5s/op confirm = N×5s), 用户首次 ack 已知
2. 用户没耐心可主动 DM "?" / "查询" → broker 回当前位置 + ETA
3. 主动推 30s 间隔会自己消耗 UTXO + 本身需要 enqueue (递归)

工作量降到 ~15 LOC (减 30s 推送 setInterval).
